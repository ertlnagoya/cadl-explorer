# Upstream CADL compiler (Lark grammar, parser, verifier, codegen), published
# on PyPI as `cadl-lang` (https://github.com/ertlnagoya/cadl). The Designer
# page uses it through `backend/services/design_service.py`. The Explorer's
# pipeline still runs on the bundled `cadl_sim/` subset. From 0.3.10 the
# Designer reads lifecycle `when:` and monitor `rule:` with its rule grammar
# (`state IN [A, B]`); older releases fall back to the expression grammar.
# From 0.3.18 expressions accept a unary minus (`x > -0.5`, Appendix A, A.10);
# with 0.3.17 and older the Designer reports such an item as not a valid
# expression. 0.3.19 to 0.3.22 add the norms, agents and stochastic
# extensions (norms and counts_as in the IR, norms-diff, the agent policies,
# PRISM export), which the Designer uses. 0.3.23 to 0.3.25 add the games and
# grounding extensions (game-check, norms-indices), quantified and wildcard
# predicates in norms, norms-check and the norms monitors of the OPA and
# Solidity targets; the Designer's read-back, checks and export use them.
# 0.3.26 adds the options --domain, --instance(s) and --version of norms-check,
# its exit status 4 and its timeout on building the model, which the Designer
# passes, and writes exact results of any size in game-check. 0.3.28 translates
# arithmetic without --domain (linear exactly, nonlinear under an assumed
# domain), lets several instances start at different observations (--starts)
# and amends several instances, which the Designer shows and passes.
